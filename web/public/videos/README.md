# Video Assets

To display your own real screen recording video of installing the extension:
1. Record a quick 15-30s screen recording showing you:
   - Downloading and extracting jobtrack-extension.zip
   - Opening chrome://extensions and toggling Developer mode
   - Clicking Load unpacked and selecting the folder
2. Save or convert your video to MP4 format.
3. Place it in this folder named:
   chrome-install-guide.mp4

The web application and installation modal will automatically detect this file and play your real video with native controls!
